# EDP Geração: aplicativo Android

Este repositório guarda apenas o instalador do aplicativo **EDP Geração**. O código-fonte não fica aqui.

## Baixar

**[Baixar o instalador (versão mais recente)](https://github.com/pisystemfase2/app-mobile-edp-geracao/releases/latest/download/edp-geracao.apk)**

Abra o link no navegador do celular. O download começa direto, sem precisar de conta no GitHub.

As versões anteriores ficam em [Releases](https://github.com/pisystemfase2/app-mobile-edp-geracao/releases).

## Instalar

1. Abra o arquivo `edp-geracao.apk` baixado, pela notificação de download ou pelo app de arquivos.
2. Se o Android avisar que a instalação de apps desconhecidos está bloqueada, toque em **Configurações**, ative **Permitir desta fonte** para o navegador e volte.
3. Toque em **Instalar**.
4. Se o Play Protect mostrar um aviso, toque em **Mais detalhes** e depois em **Instalar mesmo assim**.

Requer Android 6.0 ou superior.
